# Руководство по запуску поискового движка.
Проект полностью контейнеризирован.

## Единственное требование
Установленный и запущенный **Docker Desktop** (или Docker Engine).

---

## Шаг 1: Подготовка данных
Чтобы не перегружать Git-репозиторий, исходные тяжелые датасеты в него не включены. Перед первым запуском необходимо:
1. Создать в корне проекта папку `data/`.
2. Положить внутрь исходный файл датасета и убедиться, что он называется строго **`Questions.csv`**.

---

## Шаг 2: Запуск и сборка контейнера
Откройте терминал в папке проекта и выполните всего одну команду:

```bash
docker compose up --build
```

### Pipeline:
1. **Сборка образа:** Docker скачает образ Python 3.12, установит пакетный менеджер `uv` и компилятор `gcc`.
2. **Компиляция:** Сработает кроссплатформенный `Makefile`, который соберет основной монолит и бинарники юнит-тестов (AVL, RB, B-Tree).
3. **Fail-fast тестирование:** Скрипт `start.sh` автоматически прогонит 40+ юнит-тестов. Если Си-код сломан, запуск прервется.
4. **Индексация (при первом запуске):** Если готовых индексов нет, Python-скрипт нарежет 500 000 строк из `Questions.csv`, а Си-бэкенд построит по ним индексные файлы для каждого дерева.
5. **Запуск:** Поднимется веб-интерфейс Streamlit.

---

## Шаг 3: Использование
После запуска Streamlit, откройте в браузере: **http://localhost:8501**

---

## Остановка и перезапуск
* Чтобы остановить сервер, нажмите `Ctrl+C` в терминале.
* Для повторного запуска достаточно написать `docker compose up`. 

## Полная очистка
Если вам нужно сбросить индексы или пересобрать проект с чистого листа:
1. Удалите текстовые дампы (`index_avl.txt`, `index_rb.txt`, `index_btree.txt`, `docs.jsonl`) из локальной папки `data/`.
2. Запустите сборку с принудительным обновлением кэша:
```bash
docker compose up --build --force-recreate
```
